# Entrega Leroy Guia

Time: Leroy Guia.

Site: https://leroy-guia-fiap.vercel.app

Vídeo: https://youtu.be/7BwmxwrZSIQ

Integrantes:

- Miguel de França Monteiro
- Isabele Maciel Viana de Freitas
- Gabriel Dantas Borges Soares
- João Vitor Lombardi Hayashi
- Maria Eduarda Santos Pedro

O pacote final está em `Leroy-Guia-entrega.zip`. Ele contém o PDF com os dados acima e `Leroy-Guia-codigo.zip`, com o projeto sem `node_modules`, `target`, builds e arquivos `.env`.

Para regenerar os arquivos no Windows, instale `reportlab` (`python -m pip install reportlab`) e rode `python entrega/gerar_entrega.py` na raiz do projeto. Confira se o vídeo está público e tem no máximo 3 minutos antes do envio à FIAP.
