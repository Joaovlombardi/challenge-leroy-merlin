O pacote final está em `Leroy-Guia-entrega.zip`. Ele contém o PDF com os dados acima e o campo de vídeo em branco, além de `Leroy-Guia-codigo.zip`, com o projeto sem `node_modules`, `target`, builds e arquivos `.env`.

Para regenerar os arquivos no Windows, instale `reportlab` (`python -m pip install reportlab`) e rode `python entrega/gerar_entrega.py` na raiz do projeto. Preencha o link do vídeo, confira se está público e tem no máximo 3 minutos antes do envio à FIAP.
